## Struktur Fungsi
- `luas_persegi_panjang(p, l)`: Menghitung luas persegi panjang berdasarkan panjang dan lebar.
- `luas_segitiga(a, t)`: Menghitung luas segitiga berdasarkan alas dan tinggi.
- `jumlah_n(n)`: Menghitung penjumlahan angka dari 1 sampai n.
- `faktorial(n)`: Menghitung nilai faktorial dari n.
- `tampilkan_menu()`: Menampilkan pilihan menu operasi matematika.
